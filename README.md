# Pandora's Jar — PITHOS: Embers of Elpis

A top-down isometric 3D action-roguelike. You're an alchemist descending
into Pandora's jar to rescue the last spirit of Hope from the evils that
escaped without her.

- [`docs/GDD.md`](docs/GDD.md) — game design doc: world, story, combat systems, perks, hub, bosses
- [`docs/TECHNICAL_SPEC.md`](docs/TECHNICAL_SPEC.md) — technical build spec: tech stack, architecture, asset pipeline, roadmap

Status: pre-implementation. No code yet — see the technical spec's phased
roadmap for the planned build order, starting with a Phase 0 bootstrap
(TypeScript + Three.js monorepo scaffold).
